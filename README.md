# Pareto Harness

> Kernel-governed runtime for reusable, evidence-verified coding procedures.

Pareto Harness 将成功任务路径沉淀为不可变、内容寻址的已验证流程，并在后续同类任务中复用。可信内核约束身份、状态、权限、预算、证据、效果和恢复；可替换策略在质量底线之上探索 Token/费用与端到端延迟的 Pareto 前沿。

Pareto Harness 不替代 LangGraph、Codex 或 Skill。它可以把这些系统作为非权威 executor、strategy 或上下文来源，负责其上层的版本固定、证据准入、外部效果、恢复和晋升治理。

## Stable Kernel Baseline

REQ-0003 至 REQ-0009 已实现并验证，作为冻结的可信内核基线保留。除明确的内核合同变更或已证明的不变量缺陷外，上层产品开发不得改写其运行时语义。具体范围与当前下一步见[状态页](docs/status.md)。

## English summary

Pareto Harness promotes independently approved, evidence-backed successful task paths into immutable verified procedure revisions. A trusted kernel enforces execution authority, while versioned strategies are compared across quality, token/cost, and latency without collapsing them into one score.
