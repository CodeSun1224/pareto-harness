# Agent workspace

- `skills/`: reusable, narrowly triggered workflows; every skill contains `SKILL.md`.
- `agents/`: role profiles for independent or specialist review.
- `templates/`: canonical templates for durable records.
- `work/active/`: short execution records for active product or kernel-contract Requirements; lightweight changes do not need a work directory.
- `work/archived/`: completed execution records retained only when useful.

Durable product or architecture truth belongs under `docs/`, not here.
