# Capture research evidence

1. Search current primary sources: official documentation or source for products, and the original paper plus released code for research.
2. Record title, direct URL, verification date, evidence tier, implementation maturity, and the exact supported claim.
3. Label the statement as implemented fact, experimental result, inference, hypothesis, or project target.
4. Distinguish an individual mechanism from an integrated production system.
5. Note workload, model, baseline, metric, and limitations for quantitative results.
6. Update `docs/research/evidence-register.md` and the relevant synthesis document without copying long passages.
7. Run the document checks.

Evidence tiers: A = official code/docs or peer-reviewed/original paper; B = author artifact or reproducible benchmark; C = credible secondary source; D = unverified lead. Do not base a key architectural claim only on C or D evidence.
