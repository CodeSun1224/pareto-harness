# Security Policy

Pareto Harness is pre-alpha and has no supported release yet.

Do not open a public issue for a suspected vulnerability involving sandbox escape, permission bypass, secret disclosure, event tampering, or unsafe promotion. Until a private reporting channel is published, contact the repository owner privately. Never include live credentials, private prompts, customer data, or exploit details in tracked files.

Security boundaries are part of the trusted kernel. Changes to permissions, effects, event integrity, sandboxing, or promotion require an RFC, threat analysis, negative tests, and an explicit rollback path.
